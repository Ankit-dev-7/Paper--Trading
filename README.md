PaperTrade 

PaperTrade is a virtual stock trading simulator built for learning and practicing stock market investing without risking real money.

The platform allows users to create an account, manage a virtual balance, buy and sell stocks, track portfolio performance, and compete with other traders on a leaderboard. It is designed to give users a realistic trading experience while keeping everything completely risk-free.

How to Run

Download or clone the project.
Open the project folder.
Run the application using a local server.
Open the website in your browser.
just click on this link for demo: https://ankit-dev-7.github.io/Paper--Trading/
